## 🎨 Project Overview

This project is a **stylized 3D car model** designed and modeled from scratch in Blender.

The goal was to create a clean and visually appealing car with simplified shapes while maintaining realistic proportions and recognizable automotive details.

## 🛠️ Tools & Technologies

- **Blender**
- 3D Modeling
- Materials & Shading
- Lighting
- Camera Composition
- Rendering

## ✨ Key Features

- Stylized car body design
- Detailed exterior modeling
- Custom wheels and tires
- Headlights and rear lights
- Smooth surface detailing
- Material and shading setup
- Studio-style lighting and rendering
